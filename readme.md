# Concept Paper Management System

A web-based system for submitting concept papers and managing their
approval through a defined workflow. It helps requestors and approvers
track each paper’s progress throughout the approval process.

## Project Demo

https://github.com/user-attachments/assets/8b2c833a-365d-49cf-b2c6-1482af9f1ce2

## Overview

The system organizes the concept paper approval process by routing
each submission through its configured approval steps. This provides
a clear process for reviewing proposals and tracking approval progress.

## Key Features

- Create and submit concept papers.
- Route submissions through a defined approval workflow.
- Review papers at the assigned approval stages.
- Track approval progress and paper status.

## Language & Tools Used

- PHP
- MySQL
- CodeIgnitor3
- LucideIcons

## Approval Process

1. The requestor creates and submits a concept paper.
2. The paper enters its defined approval workflow.
3. Assigned approvers review it in the configured sequence.
4. The paper reaches final approval after completing the required steps.

## Purpose

To streamline concept paper approvals, improve visibility into
pending reviews, and keep submissions organized in one system.
